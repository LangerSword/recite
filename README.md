# recite

**Design it by voice. Build it by voice. Hear how it was made.**

recite is a voice-native studio:

- **Studio**: speak your system and watch the diagram draw itself. Refine by voice. Export SVG / Mermaid.
- **Record**: the real audio next to the commits it produced. Press play on a commit and hear the words that made it.
- **World**: the living hero adapts ThreeUI's Sylva (living green): the authored scene runs byte-exact, and `tools/build-recite-world.mjs` derives recite's copy, routes and the speech-to-design panel from it with anchored rewrites.

The first record is recite's own: this repo is being designed and built entirely by voice.
